\newcommand{\capAttrZ}{How often does \scheme miss each attribute, relative to random? For each attribute of an instance, we count the closed-set samples for which the instance predicted by \scheme has a different value of this attribute than the true instance, and divide by the same count for an instance drawn at random among the \fgAttrClasses{}: $0\%$ means that the attribute is never missed, $100\%$ that it is missed as often as at random. For example, \scheme misses the system prompt for \nAttrMissSP{} of the samples, against \nAttrRandSP{} at random, hence \nAttrRelSP{}. Closed-set setting, instance classifier of Section~\ref{sec:flips_scheme}, $N_t{=}\fgAttrNt$.}
